#### Sobre

Conecto engenharia elétrica, automação e desenvolvimento de software para criar ferramentas de consulta, aquisição e análise de dados. Atuo com manutenção e operação de sistemas elétricos industriais e desenvolvo projetos voltados à infraestrutura energética, sistemas embarcados e automação de tarefas.

Meu portfólio reúne aplicações em Python, firmware em C++ para ESP32, geoprocessamento e integrações com APIs e Google Sheets.

#### Projetos em destaque

- **[EnerAtlas](https://github.com/patrick9kk/eneratlas)** — aplicação em Python para consultar a infraestrutura energética brasileira com dados da EPE, ANEEL e ONS. Reúne mapa interativo, filtros, fichas técnicas, exportação e, na versão local, importação, atualização e cruzamentos espaciais. Disponível na web e como aplicativo para Windows. **[Abrir o mapa](https://patrick9kk.github.io/eneratlas/)**.
- **[Gerador de etiquetas com código de barras](https://github.com/patrick9kk/gerador-etiquetas-codigo-barras)** — aplicativo em Python e Streamlit que importa códigos de PDF ou Excel e gera etiquetas com códigos de barras ou QR Code em PDF, com ajuste do layout de impressão.
- **[ESP32 + MPU-6050 + cartão SD](https://github.com/patrick9kk/ESP32-MPU6050-GPS-SD-Datalogger)** — firmware em C++/Arduino para registrar aceleração, velocidade angular e temperatura em cartão SD, apoiando análises posteriores de movimento e vibração. A integração com GPS permanece como melhoria futura.
- **[Buscador de preços no Google Sheets](https://github.com/patrick9kk/Buscador-de-Precos-Google-Sheets)** — automação em Google Apps Script para pesquisar preços, filtrar valores discrepantes e calcular estatísticas na planilha, com implementações que integram Serper, Gemini ou Perplexity.
- **[Mapa de linhas de transmissão e subestações](https://github.com/patrick9kk/Mapa-LTs-Subestacoes-Brasil-QGIS)** — projeto de mapeamento da infraestrutura elétrica brasileira em QGIS.
